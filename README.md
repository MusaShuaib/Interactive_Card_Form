# Interactive Card Details Form

A responsive interactive credit card details form built as a solution to the **Frontend Mentor – Interactive Card Details Form** challenge.

The project allows users to enter their card information and see the details update live on the virtual card. It also includes client-side form validation and a completed confirmation state.

## Features

- Live cardholder name update
- Live card number formatting
- Live expiration date update
- Live CVC update
- Card number validation
- Expiration month and year validation
- CVC validation
- Required-field validation
- Error messages for invalid inputs
- Completed/confirmation state
- Continue button to reset the form
- Responsive design for mobile and desktop screens
- Custom Google Font using Space Grotesk

## Built With

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Media Queries
- Regular Expressions
- DOM Manipulation
- Event Listeners
